# MediaNexpo

A lightweight, open-source local audio and video player built with Jetpack Compose and Media3 / ExoPlayer.

## Features
* **Custom Themes**: Dynamic palette selector with 20+ color schemes.
* **Light / Dark / System Modes**: Seamless UI theme adaptation.
* **Audio Visualizers**: Multiple real-time FFT spectrum styles (Bars, Waveform, Pulse, Dot Matrix, etc.).
* **Audio Effects**: Built-in Equalizer, Bass Boost, Virtualizer, and Pre-amp Gain control.
* **Media Scanning**: SAF custom folder support alongside MediaStore scanning.
* **Video Playback**: Local video library scanner and integrated player.
